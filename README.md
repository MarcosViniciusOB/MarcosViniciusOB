## 📂 Projetos em Destaque
 
<details>
<summary><b>🚗 Loca Mais - Sistema de Gestão de Locadora</b></summary>
<br>
Solução desktop robusta e profissional para gerenciamento completo de frotas, clientes e reservas de locadoras de veículos. Desenvolvido com foco em <b>integridade de dados</b> e <b>experiência do usuário</b>.
<br>
<br>

| Aspecto | Detalhes |
|--------|----------|
| **Linguagens** | Java, SQL |
| **Interface (GUI)** | Java Swing (GridBagLayout, BorderLayout) |
| **Persistência** | MySQL com JDBC |
| **Design Patterns** | Singleton, Factory |
| **Destaques Técnicos** | Transações ACID, Internacionalização (i18n) |
| **Idiomas Suportados** | PT-BR, EN-US, ES-ES (troca instantânea) |
| **📦 Repositório** | [Ver Código](https://github.com/MarcosViniciusBrandao/LocaMais) |
 
<br>

<b>Stack Técnico Completo:</b>
```
Frontend: Java Swing (sem frameworks externos)
Backend: JDBC puro com transações gerenciadas
Database: MySQL com design relacional otimizado
Padrões: ACID, Singleton, Factory, MVC
```
 
<b>Funcionalidades Principais:</b>
- ✅ Autenticação com suporte a múltiplos idiomas
- ✅ Cadastro e gerenciamento de frota de veículos
- ✅ Gestão de clientes com validação de CPF
- ✅ Sistema completo de reservas com validação de disponibilidade
- ✅ Devolução de veículos com atualização automática de estoque
</details>

<details>
<summary><b>📊 Algoritmos de Ordenação em C</b></summary>
<br>
    
Biblioteca modular de **alta performance** contendo implementações clássicas de algoritmos de ordenação. Projeto educacional focado em análise de complexidade, estabilidade algorítmica e comparação prática de desempenho entre algoritmos  $O(n^2)$ e  $O(n \log n)$.
 
<br>

| Aspecto | Detalhes |
|--------|----------|
| **Linguagem** | C |
| **Estrutura** | Modular (`.h`, `.c`, `main.c`) |
| **Algoritmos** | 8 implementações clássicas |
| **Foco** | Análise Big O, Estabilidade, Performance |
| **Complexidade** | De $O(n^2)$ até $O(n+k)$ |
| **Memória** | De $O(1)$ até $O(n)$ |
| **📦 Repositório** | [Ver Código](https://github.com/MarcosViniciusBrandao/Algoritmos-de-Ordenacao) |
 
<br>
<b>Destaques de Engenharia:</b>
<br>
<br>

🔬 <b>Análise Comparativa Completa:</b> Tabelas detalhadas mostrando complexidade de tempo, espaço e estabilidade — ferramenta essencial para escolher o algoritmo certo para cada caso.
 
⚙️ <b>Estabilidade Algorítmica:</b> Implementações mantêm elementos iguais na ordem original quando necessário — crucial para ordenações sequenciais em dados multidimensionais.
 
📦 <b>Código Modular:</b> Interface clara (`.h`), implementação limpa (`.c`) e programa de teste interativo — pronto para produção ou como material didático.
 
💾 <b>Manipulação Eficiente de Memória:</b> Uso avançado de ponteiros e alocação dinâmica — demonstra domínio de gerenciamento de recursos em C.
 
🎯 <b>Casos de Uso Práticos:</b> Documentação clara indicando quando usar cada algoritmo (arrays pequenos vs grandes, dados quase ordenados, intervalos limitados, etc).
</details>
